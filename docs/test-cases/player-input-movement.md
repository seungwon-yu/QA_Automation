# 입력 및 플레이어 동작 테스트 케이스

## 개요

| 항목 | 내용 |
| --- | --- |
| 그룹 ID | TC-GROUP-02 |
| 대분류 | 입력 및 플레이어 동작 |
| 우선순위 | High |
| 주요 기법 | 상태 전이, 동등 분할 |
| 목적 | 플레이어 입력과 이동 규칙을 검증한다. |

## 후보 테스트 케이스

| 테스트 ID | 시나리오 | 기대 결과 | 상세화 상태 |
| --- | --- | --- | --- |
| TC-002-01 | 지상에서 점프 | 플레이어가 위로 이동하고 공중 상태가 된다. | 후보 |
| TC-002-02 | 공중에서 점프 | 두 번째 점프가 거부된다. | 후보 |
| TC-002-03 | 점프 후 착지 | 충분한 루프 진행 후 플레이어가 지면으로 돌아온다. | 후보 |
| TC-002-04 | 착지 후 재점프 | 착지 후 다시 점프할 수 있다. | 후보 |

## Evidence 기준

- `state.json`
- `metadata.json`
- 필요 시 `timeline.json`
- 브라우저 입력 검증에서는 `screenshot.png`, `console-log.json`

## Classification Basis 방향

- 입력이 정상 전달됐고 플레이어 위치나 속도가 expected와 다르면 `PRODUCT_FAIL` 후보이다.
- 브라우저 포커스, 키 입력 전달, locator 문제가 있으면 `TEST_FAIL` 후보이다.
- 입력 전달 여부를 확인할 근거가 부족하면 `REVIEW_REQUIRED`로 둔다.

## 상세화 예정

이 그룹은 점프와 중복 점프 방지의 핵심 로직을 포함한다. 이후 E2E와 하네스 단위 테스트의 expected/actual metadata를 맞춰 상세화한다.
