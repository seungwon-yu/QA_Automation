# 후속 작업 우선순위

이 문서는 기존 Sprint 2 후보 문서를 현재 신입 포트폴리오 목적에 맞게 갱신한 것이다. 완료 상태의 단일 기준은 [현재 상태](project-status.md)이다.

| 순서 | 작업 | 완료를 판단할 증거 |
| --- | --- | --- |
| 1 | 마지막 프레임·충돌 경계·재시작 회귀 | 테스트와 사례 보고서 |
| 2 | 캡처 실패 보존·명확하지 않은 오류 검토 | 의도 실패 실험 결과 |
| 3 | GitHub CI 실제 실행 확인 | 실행 URL와 artifact |
| 4 | 대표 화면/리포트로 제출 자료 구성 | 직접 열 수 있는 결과 샘플 |
| 후속 | 장시간/다중 브라우저/분류 정확도 대규모 측정 | 이번 필수 범위 밖 |

새 프레임워크·AI 분석 기능 추가보다 검증 대상 선정, 재현, 근거 설명이 우선이다.
